# Movie Watch List

A very simple React app for keeping track of movies you watch.

## Requirements included
- Add a movie
- Remove a movie
- Write or edit a review
- Rate each movie from 1 to 5 stars
- Show the rating with star emojis

## Run the project

1. Install Node.js if you do not have it.
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

The movie list is stored in React state, so it resets when the page is refreshed.
